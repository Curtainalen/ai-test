# 风险清单与二期建议

## 已知风险

- 当前原始文件保存在本地共享卷，生产多节点需要迁移到对象存储并增加病毒扫描。
- OCR 仅为低置信度人工校正占位；扫描 PDF 不会自动识别文字。
- 前端当前以 JSON 编辑复杂步骤，适合 MVP 验收，后续应拆成可视化提取/断言/变量编辑器。
- Redis/RQ 与 PostgreSQL 的真实容器 E2E 依赖运行中的 Docker daemon；CI/交付环境必须执行。
- OpenAPI `$ref` 保留在快照中但未完整展开；复杂 callback/webhook 会产生告警增强项。
- 前端生产依赖已消除 npm audit 高危项；React Router 6.30.6 仍有 2 个中危公告，官方自动修复要求升级到 7.x。为遵守一期 React Router 6 技术冻结，暂不做破坏性主版本升级；应用不得把不可信输入直接传给导航/重定向目标，二期评估 7.x 迁移。
- 前端生产包当前约 1.2 MB（gzip 约 383 KB），功能正确但需要按路由和 Ant Design 组件做代码分割。

## 二期建议

- 完整 OCR 与对象存储、文件病毒扫描、保留策略。
- UI actuator、受控探索、截图/Trace/DOM 证据。
- LLM 多协议网关和需求评审/场景候选增强，继续保持人工确认。
- 更丰富的报告导出、趋势看板和执行器可观测性。
- 完整 MCP 只读适配器；写入/执行工具继续走审批、幂等和审计。
