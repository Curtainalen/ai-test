# 一期验收用例冻结

| # | 操作 | 预期 |
|---:|---|---|
| 1 | Owner 创建项目和测试环境 | 项目和环境可查询，非成员不可见 |
| 2 | 上传示例需求文档 | HTTP 快速返回 pending；Worker 完成后可见 ContentBlock 及来源定位 |
| 3 | 编辑并确认“用户登录”模块 | 状态为 confirmed，关联文档版本和来源块 |
| 4 | 导入示例 OpenAPI 并确认差异 | 可见模块/接口；再次导入显示新增/修改/删除/冲突，不静默覆盖 |
| 5 | Preview/Run 登录接口 | Preview 不落调试历史；Run 保存脱敏请求/响应 |
| 6 | 创建两步场景 | 第一步提取 token，第二步通过 `${access_token}` 引用 |
| 7 | 执行未确认场景 | 返回 `SCENARIO_NOT_CONFIRMED` |
| 8 | 确认并执行场景 | WebSocket 依次看到 pending/running/步骤终态/任务终态；重连先获得当前快照 |
| 9 | 查看报告 | 展示脱敏步骤事实、断言、耗时、错误分类、复现顺序和需求覆盖 |
| 10 | 修改场景后查看旧报告 | 报告内容和场景快照不变 |
| 11 | 非成员访问资源 | 返回 403，且不泄露资源是否存在 |
| 12 | 相同幂等键重复提交或 Worker 恢复 | 返回同一任务；报告唯一；已完成步骤不重复写入 |
