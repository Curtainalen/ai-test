# 智能协同云图库需求文档

> 探索来源：`https://www.curtain12138.icu/`，公开页面实际走查。
>
> 探索范围：未登录状态下的主页、搜索框、分类标签、分页、登录页；登录后页面和后台管理能力未使用真实账号验证，以下内容标记为“待确认”。

## 产品概览

智能协同云图库是一个面向团队的图片资源平台。公开首页提供图片浏览、关键词搜索、分类筛选和分页浏览；用户可以进入登录页，登录后预计可使用创建图片及更多协同能力。页面品牌文案为“智能协同云图库”，英文副标题为“ENTERPRISE CLOUD GALLERY”。

## 公开首页与资源浏览

用户打开站点后进入主页。顶部包含品牌 Logo、主页入口、创建图片入口和登录入口。主体提供搜索框“从海量图片中搜索”和“搜索”按钮。

资源分类包括：全部、模板、电商、表情包、素材、海报。首页还展示标签：热门、搞笑、生活、高清、艺术、校园、背景、简历、创意。资源以图片卡片网格展示，卡片包含图片、图片名称和“默认”标识。公开探索中“全部”分类展示了“动漫10”“动漫9”“动漫8”“动漫7”“动漫5”“动漫6”“动漫4”“动漫3”“动漫2”“动漫1”“屏幕截图 2025-05-01 200848”“熊猫20”等资源。

### 正常流程

1. 用户进入主页。
2. 页面加载资源列表、分类标签和分页器。
3. 用户可点击分类切换资源集合。
4. 用户可输入关键词并点击搜索。
5. 用户可使用上一页、下一页和页码切换资源。
6. 用户可点击资源卡片查看资源详情或执行站点提供的后续操作（详情行为待登录/点击验证）。

### 异常与边界

- 搜索关键词为空时点击搜索，系统应保持当前列表或给出明确提示，不应出现空白崩溃页面。
- 搜索不存在的关键词时，应显示“暂无数据”或等价空状态，并保留分类和返回入口。
- 关键词包含空格、中文、特殊字符时不得导致脚本执行或服务端错误。
- 快速连续切换分类和分页时，旧请求结果不能覆盖新选择。
- 当前分类无资源时显示空状态；实际探索中“模板”分类显示“暂无数据”。
- 图片加载失败时应显示占位图或失败提示，不影响其他卡片使用。
- 分页边界：第一页不能继续上一页，最后一页不能继续下一页。

## 分类与标签筛选

分类用于选择资源类型，标签用于快速选择常用主题。分类和标签应能够组合使用，组合筛选后的结果、总数和分页器保持一致。

### 业务规则

- “全部”表示不限定资源分类。
- 分类切换后应从第一页开始展示结果。
- 标签选择后应保留当前分类条件。
- 取消筛选后恢复默认资源列表。
- 无权限的私有资源不能出现在公开列表中。

## 用户登录与注册

点击“登 录”进入登录页。登录页展示平台 Logo、标题“智能协同云图库平台”、英文副标题“ENTERPRISE CLOUD GALLERY”、账号输入框“请输入账号”、密码输入框“请输入密码”、密码可见性切换、登录按钮，以及“没有账号？去注册”入口。

### 登录正常流程

1. 用户输入已注册账号和密码。
2. 系统校验凭证。
3. 登录成功后建立用户会话并返回主页或用户上次访问页面。
4. 登录用户可以访问需要鉴权的创建图片和协同功能。

### 登录异常与安全要求

- 账号为空、密码为空时禁止提交并显示字段级提示。
- 账号不存在或密码错误时使用统一错误提示，不泄露账号是否存在。
- 连续失败登录应触发限流或二次校验（具体阈值待确认）。
- 密码输入默认掩码，可切换显示但不应写入日志、URL、前端错误消息或需求评审结果。
- 登录成功后刷新页面会话仍有效；退出后受保护页面应回到登录页。
- 登录接口应防止重复提交和 CSRF/暴力尝试。

## 创建图片

主页顶部提供“创建图片”入口。未登录公开探索仅确认入口存在，未执行真实创建操作。以下为待确认需求边界，需产品或登录后验收补充：

- 用户可创建图片资源或上传图片。
- 创建时至少填写图片名称、分类、标签和资源内容。
- 资源应支持预览、取消和保存。
- 保存成功后资源进入当前用户或团队的资源列表。
- 非法文件类型、超大文件、空名称和重复提交应被明确拒绝。
- 创建失败时不应产生半成品资源。

## 图片资源详情与权限

资源卡片展示图片名称和默认状态。详情页和资源权限在公开探索中未验证，按待确认需求记录：

- 用户可以查看图片预览、名称、分类、标签和创建信息。
- 公开资源可被有权限的用户查看。
- 私有资源仅资源拥有者和被授权成员可查看。
- 未授权用户访问资源详情、下载或编辑接口时返回统一无权限错误。
- 删除、编辑、授权等危险操作需要二次确认，并记录审计信息。

## 团队协同与资产管理（待确认）

产品名称和“ENTERPRISE CLOUD GALLERY”文案表明平台可能面向团队协作。以下能力尚未使用登录账号验证，不能视为已上线事实：

- 团队成员、角色和资源访问范围管理。
- 资源收藏、分享、评论或协作编辑。
- 图片版本、操作记录和审计追踪。
- 管理员对分类、标签和资源状态进行维护。

## 接口自动化落地

接口自动化以被测站点实际 API 文档为准。当前需求文档先定义业务验收和数据契约，待导入站点 OpenAPI/Swagger 后，将接口按“资源查询”“认证”“图片资源”“权限”分组。不得根据页面 URL 猜测接口路径；未在 OpenAPI 中出现的接口先标记为待补充。

### 接口场景建议

| 场景 | 需求测试点 | 请求链路 | 关键断言/提取 |
|---|---|---|---|
| 公开资源搜索 | 关键词搜索动漫资源、空关键词搜索 | 资源列表接口，Query 传关键词和分页 | HTTP 200；结果名称/标签匹配；空结果结构稳定 |
| 分类与分页 | 模板分类空状态、分类切换重置分页、分页首尾边界 | 资源列表接口，传分类/标签/page/page_size | 总数、当前页、上一页/下一页边界一致 |
| 登录成功 | 登录成功保持会话 | 登录接口 | HTTP 2xx；提取 Token 或会话标识；敏感值只保留变量引用 |
| 登录失败 | 登录空字段、错误密码不泄露账号存在性 | 登录接口 | HTTP 4xx；不同账号失败返回统一错误语义 |
| 资源权限 | 退出后访问受保护能力、资源权限隔离 | 详情/创建/编辑/删除接口 | 无 Token 或非授权用户返回统一 401/403；不泄露资源内容 |
| 创建图片 | 创建图片非法文件拒绝 | 上传/创建接口（以 OpenAPI 为准） | 合法资源创建成功；非法类型/超限/重复提交明确失败且无半成品 |

接口场景使用平台现有请求模型：Query、Path、Header、Cookie、Body、鉴权、环境变量、变量提取和响应断言。前一步登录得到的 Token 只能通过变量传递到后续请求；密码、Token、Cookie 和图片真实内容必须使用 `secret://` 引用或受控文件引用。

## UI 自动化落地

UI 自动化采用“受控探索 → 候选审核 → 场景确认 → 隔离执行”。探索环境的 `start_url` 为 `https://www.curtain12138.icu/`，允许路径应至少包含 `/`，登录和创建图片路径需在产品确认后显式加入；不得默认全站扫描。

### UI 探索与场景

1. 公开首页探索：验证品牌、搜索框、搜索按钮、分类 Tab、标签和资源卡片。
2. 搜索探索：输入“动漫”，提交搜索，验证结果区域或“暂无数据”空状态。
3. 分类探索：切换“模板”，验证空状态；切换回“全部”，验证资源列表恢复。
4. 分页探索：验证页码、上一页和下一页的可用状态及边界。
5. 登录探索：点击“登 录”，验证账号框、密码框、眼睛图标、登录按钮和“去注册”链接。
6. 登录后流程：仅使用测试账号和授权范围探索创建图片；提交、删除等有副作用操作必须先获得人工授权。

页面、元素和定位器应沉淀为 UI 资产。定位器优先使用 `data-testid`、role+name、label/placeholder/name，再使用稳定 CSS，XPath 仅作兜底。探索生成的页面、元素和定位器候选必须经过人工审核；AI 候选不能直接变成正式场景。

### UI 场景与需求测试点映射

| UI 场景 | 关联测试点 | 预期结果 |
|---|---|---|
| 公开首页浏览 | 公开首页加载默认资源 | 首屏结构和资源卡片可见 |
| 搜索动漫 | 关键词搜索动漫资源 | 搜索结果与空状态均可被稳定识别 |
| 模板空状态 | 模板分类空状态 | 显示“暂无数据”，页面不崩溃 |
| 登录校验 | 登录空字段校验、密码掩码与显示切换 | 字段提示、掩码和切换状态正确 |
| 登录跳转 | 未登录创建图片拦截 | 点击创建图片进入登录或出现鉴权提示 |
| 授权资源访问 | 资源权限隔离 | 非授权用户看不到私有资源或操作按钮 |

UI 正式执行必须使用独立浏览器上下文和指定测试环境，实时回写步骤状态，并保存脱敏截图、Trace、DOM 快照和错误分类。定位器失效时只生成候选修复，人工确认后才能更新资产或重跑。

## 需求到自动化的使用规则

只有 `confirmed` 的需求模块和 `approved` 评审产生的测试点，才能被接口场景或 UI 探索/场景选择器引用。推荐上下文标签格式为：`公开首页浏览 · 公开首页加载默认资源`、`登录校验 · 登录空字段校验`。需求版本或模块正文变更后，关联场景进入待复核，旧测试点不得继续作为有效上下文。

测试数据只能引用安全存储中的账号、密码、图片文件和 Token，例如 `secret://curtain/gallery/user`、`secret://curtain/gallery/password`，不得把真实凭证写入测试点、Prompt、日志、截图、Trace 或报告。

## 待产品确认事项

- 登录后默认落地页和会话有效期。
- 创建图片的真实字段、支持的文件格式、大小限制和是否支持 AI 生成。
- 图片详情、下载、分享、收藏、评论和协同编辑是否上线。
- 分类与标签是否允许用户创建或仅管理员维护。
- 私有资源、团队资源和公开资源的权限模型。
- 搜索是否支持模糊匹配、拼音、分页总数和排序方式。
- 是否存在资源审核、回收站、版本管理和审计日志。
