# 智能协同云图库自动化实施需求

## 模块：公开首页

页面：首页（url: `https://www.curtain12138.icu/`）

### 需求-GALLERY-HOME-01 默认加载

描述：进入首页后展示公开图片资源、搜索、分类、标签和分页。

前置：未登录；浏览器已打开目标地址。

验收标准：显示 Logo“智能协同云图库”、主页、创建图片、登录入口；显示搜索框“从海量图片中搜索”和“搜 索”按钮；显示“全部、模板、电商、表情包、素材、海报”；资源列表或“暂无数据”可见；页面无 500 错误。

### 用例-GALLERY-HOME-01-UI 默认加载首页 [UI]

步骤：1. 打开首页。2. 等待资源列表或空状态。

断言：上述验收标准全部满足；保存页面截图和资源列表 DOM 快照。

### 用例-GALLERY-HOME-01-API 获取公开资源 [API]

请求：`GET` 资源列表接口（路径待从 OpenAPI 确认），Query `page=1`、`page_size=12`。

断言：HTTP 200；响应为 JSON；列表数量不超过 12；包含分页信息；匿名请求可访问。

## 模块：图片搜索

页面：首页。

### 需求-GALLERY-SEARCH-01 关键词搜索

描述：用户输入关键词后刷新图片列表；无结果时显示稳定空状态。

### 用例-GALLERY-SEARCH-01-UI-01 搜索动漫图片 [UI]

前置：首页资源已加载。

步骤：1. 定位 placeholder 为“从海量图片中搜索”的输入框。2. 输入变量 `${search_keyword}`（值：动漫）。3. 点击“搜 索”。4. 等待列表或空状态。

断言：输入值为“动漫”；列表刷新或显示“暂无数据”；页面无 Internal Server Error；有结果时至少一张图片卡片可见。

证据：搜索完成截图、DOM 快照。

### 用例-GALLERY-SEARCH-01-UI-02 不存在关键词 [UI]

步骤：输入 `${not_found_keyword}`（值：不存在的随机关键词-987654）并搜索。

断言：显示“暂无数据”或等价空状态；搜索框、分类和分页仍可用；页面不白屏。

### 用例-GALLERY-SEARCH-01-API-01 关键词查询 [API]

请求：`GET` 资源列表接口（路径待从 OpenAPI 确认），Query `keyword=${search_keyword}`、`page=1`、`page_size=12`。

断言：HTTP 200；返回列表和分页字段；有结果时名称或标签匹配“动漫”；不存在关键词返回空列表而非 500。

## 模块：用户认证

页面：登录页（由首页“登 录”进入）。

### 需求-GALLERY-AUTH-01 登录表单

验收标准：显示账号框“请输入账号”、密码框“请输入密码”、眼睛图标、登录按钮和“去注册”链接。

### 用例-GALLERY-AUTH-01-UI-01 登录页结构 [UI]

步骤：点击“登 录”。

断言：显示标题“智能协同云图库平台”、账号框、密码框、密码显示切换、登录按钮和“去注册”。

### 用例-GALLERY-AUTH-01-UI-02 空字段校验 [UI]

步骤：账号和密码均为空，点击“登 录”。

断言：不能登录；账号和密码显示字段提示；页面不白屏。

### 用例-GALLERY-AUTH-01-UI-03 错误密码 [UI]

前置：账号 `${gallery_user}`；密码使用错误值。

断言：停留登录页；显示统一失败提示；不泄露账号是否存在；密码不出现在 URL、日志和错误提示。

### 用例-GALLERY-AUTH-01-API-01 登录成功 [API]

请求：登录接口（方法、路径和字段待从 OpenAPI 确认）；账号使用 `${gallery_user}`，密码使用 `${gallery_password}`。

断言：返回成功状态和会话标识；提取 `access_token`（如系统使用 Token）；敏感值不写日志。

变量提取：`access_token` 从登录响应 Token 字段提取。

### 用例-GALLERY-AUTH-01-API-02 登录失败 [API]

请求：错误密码或随机账号。

断言：返回 4xx；失败语义统一；不返回堆栈、数据库信息或账号存在性差异。

## 执行约束

- UI 起始地址为首页，允许路径必须显式配置；默认不全站扫描。
- UI 定位优先级：`data-testid` → role+name → label/placeholder/name → 稳定 CSS → XPath。
- AI 生成的 API/UI 候选必须人工批准后才能形成正式场景。
- 正式执行使用隔离浏览器上下文；失败保存脱敏截图、Trace、DOM 快照或 API 请求/响应快照。
- 需求模块变更后，关联测试场景进入待复核；旧测试点不得继续作为有效上下文。
